# Product Direction Summary

The app should be framed as a phone-first agent control center for remote coding work.

## Best positioning
- Claude Code-style experience on Android
- lightweight remote control surface
- agent monitoring + guidance + interruption
- not a full IDE, but a focused companion to your coding workflow

## Core promise
From your phone, you can:
- connect to a remote host,
- see active agents,
- send new instructions,
- follow output,
- nudge or stop work,
- inspect files and repo context.

## Visual language
- calm, rounded cards,
- strong status hierarchy,
- high contrast for working/blocked/idle states,
- mobile-friendly spacing and tap targets,
- minimal but clear information density.

## Suggested product name direction
- Herdr Remote
- Agent Command
- Claude Pocket
- Remote Codex
- Agent Board

## Suggested first-screen story
The home screen should immediately answer three questions:
1. What is connected?
2. What is happening right now?
3. What should I do next?
