NAME

shep — pocket controller for autonomous AI coding swarms

SYNOPSIS

$ curl -fsSL https://sheperd.sh | sh

DESCRIPTION

Shep is a minimalist, battery-efficient companion remote designed for Daylight Computer e-paper tablets, dual-screen foldables, and pocket devices. It bridges Unix domain sockets to local TCP/tailscale mesh networks without telemetry or cloud bloat.

CAPABILITIES

  • WARM CACHING: 0ms transition latency between agent sessions and screen rotations.
  • E-PAPER TUNING: Pure contrast rendering for sunlight and zero-refresh ghosting.
  • ADAPTIVE SPLIT: Collapsible master sidebar with interactive live streaming panes.
  • DANGER LEVEL: Runtime switchable between 0 Danger and Dangermaxxing auto-approval.
  • UPSTREAM CORE: Native integration with herdr.dev protocol and forthcoming remotes.
